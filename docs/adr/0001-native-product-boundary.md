# Native product boundary

TailOps treats the signed WidgetKit extension and hidden Swift host app as the supported macOS product. The Node browser dashboard remains an unsupported experiment for full-screen visualization, telemetry exploration, and agent-directory prototyping. The native path owns Tailscale commands, shared state, Keychain-backed Wormhole configuration, and Finder Services, while the browser path exposes unauthenticated local endpoints and static agent prototype data. Browser experiments do not change native support claims or installed-widget proof requirements.
