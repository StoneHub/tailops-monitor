TailOps Trust Hardening

Branch: codex/tailops-trust-hardening. Objective: make the widget honest, the local server safe by default, and command execution bounded before adding more product surface.

Scope gate: this tranche does not bundle Magic Wormhole, redesign the full settings surface, or add a transfer center. The security follow-on was subsequently completed on the same branch after explicit approval.

Parallel lanes

LaneScopeAcceptance
Browser safetyLoopback default, explicit LAN opt-in, restrictive CORS, HTTP integration coverage.Default server is unreachable through non-loopback binding; existing local workflow remains one command.
Widget truthWidget refresh requests host telemetry; persist refresh health; display snapshot age and stale/error state.The refresh control cannot merely repaint cached data, and the widget never labels old data as newly updated.
Process reliabilityShared asynchronous runner with concurrent pipe draining, timeout, cancellation, and bounded captured output.Tailscale and Wormhole processes cannot wait forever or deadlock on full pipes.
