# TailOps 1.2.0

TailOps now shows the health of your Linux Fleet nodes. Add an SSH host such as fcfdev under Settings > General > Fleet health, and its widget tile shows a line like "Healthy · 38 °C · disk 45%", turning into a warning that names the problem when a service fails, the disk fills, memory runs low, or it runs hot.

- Reads the node's tailopsd 0.3.0 health file over your existing SSH login every 15 minutes; the file carries no peer list or addresses.
- A node that stops answering keeps its last reading, marked stale after 45 minutes.
