# TailOps 1.1.0

TailOps now explains the state of your tailnet: a status line when Tailscale is off, needs login, reports health warnings, or uses an exit node, plus each device's route (Direct, DERP region, or peer relay) and node keys expiring within a week.

- Default widget actions follow each device's operating system: SSH, Screen Sharing, and Copy IP for Macs; Files for Windows; no SSH button for phones.
- Status reaches the widget before pings run, pings run four at a time, and TailOps refreshes after wake and network changes. The widget no longer polls every 15 minutes.
- The large widget no longer clips its bottom row, and offline hosts collapse into a count.
- The Wormhole listener accepts only tailnet addresses, starts only after pairing, and no longer crashes on bad input; the widget shows incoming notices immediately.
- Settings > General adds Check for Updates, which installs future releases after verifying their signature.
- The unsupported browser dashboard is retired (tag browser-dashboard-final).
